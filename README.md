# 我喵本命對決 — 靜態網站範本

這個資料庫包含一個小型互動網頁遊戲：「我喵本命對決」。

說明
- 開啟 index.html 就能在瀏覽器中遊玩（不需伺服器）。
- 將 logo 圖檔放到 `assets/unilions-logo.png`（或修改 index.html 的 `<img>` 路徑）。

部署（GitHub Pages）
1. 確認 repo 有 index.html（已存在）。
2. 前往 Settings → Pages，選擇 Branch: main、Folder: /（root），儲存。
3. 幾秒到幾分鐘後，網站會在 https://{owner}.github.io/{repo}/ 可存取。
